# Smart Calculator 🧮

An advanced and versatile web-based calculator powered by PyScript, HTML5, and CSS3. This project handles everything from basic arithmetic to complex binary operations and geometric mensuration.

## 🚀 Features

### 🔢 Arithmetic & Logic
- **Arithmetic Operations:** High-precision basic math calculations.
- **Logical Operations:** Seamless evaluation of logical expressions.

### 💻 Binary Operations
- **Binary Arithmetic:** Direct addition and subtraction of binary numbers.
- **Base Conversion:** Effortless conversion between Binary and Decimal numeral systems.

### 📐 Mensuration Module
Comprehensive geometric calculations:
- **2D Shapes:** Calculate Area and Perimeter for rectangles, squares, triangles, and more.
- **3D Shapes:** Calculate Volume, Total Surface Area (TSA), and Curved Surface Area (CSA) for cubes, cuboids, cones, and other solid figures.

## 🛠️ Technologies Used
- **PyScript:** Executes Python logic directly within the browser.
- **HTML5:** Provides the structure for the web application.
- **CSS3:** Delivers a responsive and modern user interface.

## 🚀 How to Use
1. Visit your live deployment link.
2. Choose your required module from the interface.
3. Input your parameters and calculate instant results.
